MameCloudRom (MCR) 是一个基于 Windows WinFsp (Windows File System Proxy) 的虚拟文件系统，专为 MAME ROM 管理设计。它实现了“延迟下载 (Lazy Download)”机制：当 MAME 请求一个本地不存在的 ROM 时，MCR 会自动从指定的远程服务器下载该文件，并无缝提供给 MAME 使用。

## 开发动机

MAME 几乎每个月都会更新，且每次更新时 ROM 的文件名与内容都可能重新编排。这导致玩家每更新一次 MAME 版本，就得对应下载几十 GB 的 ROM 合集更新。如果你想玩某款游戏（例如 `pacman`），却因为新版 MAME 对应不到旧版 ROM 而无法启动，那是一件非常令人沮丧的事情。

许多第三方存档网站 (Archive sites) 会即时更新与最新 MAME 版本对应的 ROM。这就是开发 MCR 的初衷：**“只有当你想玩某款游戏时，代理程序才即时去抓取对应的 ROM”**。

它设计用来解决 95% 玩家都会遇到的“ROM 版本地狱”，把时间留给游戏，而不是研究文件。本项目的设计目标在于研究与验证文件系统代理与延迟获取机制，而非提供或推广任何特定内容的获取方式。

## 主要特色 (v1.0)

*   **即时下载**：只有在打开文件时才会触发下载，节省硬盘空间。
*   **极致稳定技术 (Extreme Stability)**：采用 v0.2 的句柄保护机制，解决了 WinFsp 2025 与资源管理器高频操作下的稳定性问题。
*   **自定义路径前缀 (Prefix)**：支持 `-zp` (Zip) 与 `-7p` (7z) 参数，可完美适应任何远程服务器的目录结构。
*   **资源管理器完整兼容**：修正了 8-byte 对齐问题，可稳定使用 Windows 资源管理器浏览 `Z:\` 盘而不崩溃。
*   **多国语言支持**：设置程序 (`setup.bat`, `config.bat`) 全面支持简中/繁中/英文。
*   **扫描性能优化 (Audit Skip)**：自动区分 MAME 的“扫描”与“读取”行为。扫描时不触发下载，大幅提升启动速度。
*   **增强型下载信息**：支持 `curl` 进度条与显示 ROM 文件大小 (MB/KB)。
*   **全自动化配置**：通过 `setup.bat` 检查环境，并使用 `config.bat` 一键设置。
*   **本地缓存**：下载过的文件存储在本地目录，下次打开无需重新下载。

## 系统需求

1.  **Windows 10/11**
2.  **WinFsp** (Windows File System Proxy) - **核心组件**
    *   **自动安装**：运行 `setup.bat` 即可自动检查并安装。
    *   **手动安装**：[WinFsp 官方网站](https://winfsp.dev/) (请确定有勾选 "Core"，开发者记得勾选 "Developer" 组件)。
3.  **curl**: Windows 10/11 内置（用于显示进度条）。
4.  **Visual Studio 2022** (选配): 仅当开发者需要自行编译源码时才需要。
5.  **MAME**: 模拟器本体。[官方下载](https://www.mamedev.org/release.php)。
6.  **第三方 ROM URL 网址**: 提供 ROM 文件下载的外部来源 (例如：`https://YourRomSite.com/download/`)。

## 快速设置 (推荐使用)

1.  运行 `setup.bat` 进行初次安装。**(日后若需变更设置，直接运行 `config.bat` 即可)**。
2.  按照提示设置您的缓存目录、驱动器盘符、来源网址与路径前缀。
3.  该脚本会建立一个 `mcr-run.bat` 启动文件。
4.  运行 `mcr-run.bat`。它会启动虚拟磁盘，並同時自动开启一个新窗口帮您运行 MAME。

## 编译步骤 (开发者使用)

若您想手动编译本项目：

1.  安装 WinFsp 时选取 **Developer** 组件。
2.  使用 Visual Studio 2022 打开项目文件夹。
3.  VS 会自动配置 CMake。
4.  选择 `Release` 配置并执行“生成全部”。
5.  或直接运行 `build.bat`。

> [!TIP]
> **免编译直接使用**：若您没有安装 Visual Studio，本项目文件夹中已包含预先编译好的 `mcr.exe`。您可以跳过编译步骤，直接进行 **快速设置**。

## 使用方法

手动启动：
```cmd
mcr.exe [-m 挂载点] [-c 缓存路径] [-u 来源网址] [-zp Zip前缀] [-7p 7z前缀] [-7z] [-d]
```

*   **无参数运行**：直接双击 `mcr.exe`，系统会自动尝试加载同目录下的 `mcr.ini`。
*   `-zp`: Zip 文件夹路径前缀 (默认: `split/`)。
*   `-7p`: 7z 文件夹路径前缀 (默认: `standalone/`)。
*   `-7z`: 启用 .7z 文件支持。
*   `-d`: 启用调试模式（显示控制台日志）。

## 工作原理

MameCloudRom 运作的流程如下：

1.  **拦截请求**：当 MAME 尝试从虚拟磁盘（如 `Z:`）读取 ROM 文件时。
2.  **WinFsp 介入**：Windows 内核将请求转交给 MCR。
3.  **本地检查**：MCR 查看本地缓存目录。若文件不存在，则进入下一步。
4.  **即时在线下载**：MCR 自动判定类别，并调用 `curl` 从远程服务器下载文件。
5.  **无缝衔接**：下载完成后，MAME 随即读取到文件并启动游戏。

## 文件结构

- **mcr.exe**: 主程序与虚拟磁盘服务。
- **setup.bat**: 主安装脚本，负责环境检查、多语系处理。
- **config.bat**: 交互式设置工具。
- **winfsp-x64.dll**: 用户模式文件系统库 (由 `setup.bat` 自动获取)。
- **mcr-run.bat**: (自动生成) 一键启动脚本。
- **mcr.ini**: (自动生成) 存储您的设置参数。
- **src/**: 源代码目录 (C++)。
- **build.bat**: 研发构建脚本。

## 支持范围与限制

*   **支持下载**：位于 `rompath` 下的游戏 ROM (`.zip`, `.7z`) 以及各式设备、BIOS 文件。
*   **不支持下载**：大型 CHD 文件（体积巨大，建议自行管理）。
*   **文件删除限制**：在虚拟磁盘 (`Z:\`) 执行删除操作**无效**，文件不会真正被移除。若需删除已下载的 ROM，请直接至您的缓存目录 (Cache) 进行操作。
