Build Instructions

  1. WinFsp Developer Components

    Install WinFsp with "Core" and "Developer" components enabled.

  2. Visual Studio 2022

    Open the project folder; CMake will auto-configure.

  3. Release Config

    Select Release and "Build All".

  4. Build Script

    Alternatively, run build.bat.
