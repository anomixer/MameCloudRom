> **v1.0 (2026-01-13 Release)**

MameCloudRom (MCR) 是一個基於 Windows WinFsp (Windows File System Proxy) 的虛擬檔案系統，專為 MAME ROM 管理設計。它實現了「延遲下載 (Lazy Download)」機制：當 MAME 請求一個本地不存在的 ROM 時，MCR 會自動從指定的遠端伺服器下載該檔案，並無縫提供給 MAME 使用。

## 開發動機

MAME 幾乎每個月都會更新，且每次更新時 ROM 的檔名與內容都可能重新編排。這導致玩家每更新一次 MAME 版本，就得對應下載幾十 GB 的 ROM 合集更新。如果你想玩某款遊戲（例如 `pacman`），卻因為新版 MAME 對應不到舊版 ROM 而無法啟動，那是很令人沮喪的。

許多第三方存檔網站 (Archive sites) 會即時更新與最新 MAME 版本對應的 ROM。這就是開發 MCR 的初衷：**「只有當你想玩某款遊戲時，代理程式才即時去抓取對應的 ROM」**。

它設計用來解決 95% 玩家都會遇到的「ROM 版本地獄」，把時間留給遊戲，而不是研究檔案。本專案的設計目標在於研究與驗證檔案系統代理與延遲獲取機制，而非提供或推廣任何特定內容的獲取方式。

## 主要特色 (v1.0)

*   **即時下載**：只有在開啟檔案時才會觸發下載，節省硬碟空間。
*   **極致穩定技術 (Extreme Stability)**：採用 v0.2 的句柄保護機制，解決了 WinFsp 2025 與檔案總管高頻操作下的穩定性問題。
*   **自定義路徑字首 (Prefix)**：支援 `-zp` (Zip) 與 `-7p` (7z) 參數，可完美適應任何遠端伺服器的目錄結構。
*   **檔案總管完整相容**：修正了 8-byte 對齊問題，可穩定使用 Windows 檔案總管瀏覽 `Z:\` 槽而不崩潰。
*   **多國語言支援**：設定程式 (`setup.bat`, `config.bat`) 全面支援繁中/簡中/英文。
*   **掃描效能優化 (Audit Skip)**：自動區分 MAME 的「掃描」與「讀取」行為。掃描時不觸發下載，大幅提升啟動速度。
*   **增強型下載資訊**：支援 `curl` 進度條與顯示 ROM 檔案大小 (MB/KB)。
*   **全自動化配置**：透過 `setup.bat` 檢查環境，並使用 `config.bat` 一鍵設定。
*   **本地快取**：下載過的檔案儲存在本地目錄，下次開啟無需重新下載。

## 系統需求

1.  **Windows 10/11**
2.  **WinFsp** (Windows File System Proxy) - **核心組件**
    *   **自動安裝**：執行 `setup.bat` 即可自動檢查並安裝。
    *   **手動安裝**：[WinFsp 官方網站](https://winfsp.dev/) (請確定有勾選 "Core"，開發者記得勾選 "Developer" 元件)。
3.  **curl**: Windows 10/11 內建（用於顯示進度條）。
4.  **Visual Studio 2022** (選配): 僅當開發者需要自行編譯源碼時才需要。
5.  **MAME**: 模擬器本體。[官方下載](https://www.mamedev.org/release.php)。
6.  **第三方 ROM URL 網址**: 提供 ROM 檔案下載的外部來源 (例如：`https://YourRomSite.com/download/`)。

## 快速設定 (推薦使用)

1.  執行 `setup.bat` 進行初次安裝。**(日後若需變更設定，直接執行 `config.bat` 即可)**。
2.  按照提示設定您的快取目錄、磁碟機代號、來源網址與路徑字首。
3.  該腳本會建立一個 `mcr-run.bat` 啟動檔。
4.  執行 `mcr-run.bat`。它會啟動虛擬磁碟，並同時自動開啟一個新視窗幫您執行 MAME。

## 編譯步驟 (開發者使用)

若您想手動編譯本專案：

1.  安裝 WinFsp 時選取 **Developer** 組件。
2.  使用 Visual Studio 2022 開啟專案資料夾。
3.  VS 會自動配置 CMake。
4.  選擇 `Release` 配置並執行「建置全部」。
5.  或直接執行 `build.bat`。

> [!TIP]
> **免編譯直接使用**：若您沒有安裝 Visual Studio，本專案資料夾中已包含預先編譯好的 `mcr.exe`。您可以跳過編譯步驟，直接進行 **快速設定**。

## 使用方法

手動啟動：
```cmd
mcr.exe [-m 掛載點] [-c 快取路徑] [-u 來源網址] [-zp Zip字首] [-7p 7z字首] [-7z] [-d]
```

*   **無參數執行**：直接雙擊 `mcr.exe`，系統會自動嘗試載入同目錄下的 `mcr.ini`。
*   `-zp`: Zip 資料夾路徑字首 (預設: `split/`)。
*   `-7p`: 7z 資料夾路徑字首 (預設: `standalone/`)。
*   `-7z`: 啟用 .7z 檔案支援。
*   `-d`: 啟用除錯模式（顯示控制台日誌）。

## 工作原理

MameCloudRom 運作的流程如下：

1.  **攔截請求**：當 MAME 嘗試從虛擬磁碟（如 `Z:`）讀取 ROM 檔案時。
2.  **WinFsp 介入**：Windows 核心將請求轉交給 MCR。
3.  **本地檢查**：MCR 查看本地快取目錄。若檔案不存在，則進入下一步。
4.  **即時線上下調**：MCR 自動判定類別，並呼叫 `curl` 從遠端伺服器下載檔案。
5.  **無縫銜接**：下載完成後，MAME 隨即讀取到檔案並啟動遊戲。

## 檔案結構

- **mcr.exe**: 主程式與虛擬磁碟服務。
- **setup.bat**: 主安裝腳本，負責環境檢查、多語系處理。
- **config.bat**: 互動式設定工具。
- **winfsp-x64.dll**: 使用者模式檔案系統函式庫 (由 `setup.bat` 自動獲取)。
- **mcr-run.bat**: (自動產生) 一鍵啟動腳本。
- **mcr.ini**: (自動產生) 儲存您的設定參數。
- **src/**: 原始碼目錄 (C++)。
- **build.bat**: 研發建置腳本。

## 支援範圍與限制

*   **支援下載**：位於 `rompath` 下的遊戲 ROM (`.zip`, `.7z`) 以及各式設備、BIOS 檔案。
*   **不支援下載**：大型 CHD 檔案（體積巨大，建議自行管理）。
*   **檔案刪除限制**：在虛擬磁碟 (`Z:\`) 執行刪除操作**無效**，檔案不會真正被移除。若需刪除已下載的 ROM，請直接至您的快取目錄 (Cache) 進行操作。
